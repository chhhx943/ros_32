# STM32F407VET6 PCB IO 连接表（LQFP100）

> 数据来源：`ros.ioc`（CubeMX 6.17）、`Core/Src/gpio.c`、`Core/Src/tim.c`、`BSP/bsp_motor.c`、`BSP/servo.c`、`BSP/physical_estop.c`。  
> LQFP100 物理脚号依据标准 datasheet 排布，打板前请对照 RM0090 / 数据手册引脚表再核一遍。  
> 电平约定：所有数字 IO 均为 **3.3V** 容忍，**禁止 5V 直连**（PB8/PB9 等 CAN 脚也只到 3.3V）。

---

## 1. 动力 / 运动控制（核心功能，必须按此接）

| 引脚   | LQFP100 | 复用功能     | 接什么           | 电气/连接要点                 |
| ---- | ------- | -------- | ------------- | ----------------------- |
| PA6  | 23      | TIM3_CH1 | **电机1 PWM**   | 推挽输出，接 TB6612 的 PWMx    |
| PA7  | 24      | TIM3_CH2 | **电机2 PWM**   | 接 TB6612 的 PWMx         |
| PB12 | 33      | GPIO_OUT | 电机1 IN1       | 推挽输出，TB6612 IN1         |
| PB13 | 34      | GPIO_OUT | 电机1 IN2       | 推挽输出，TB6612 IN2         |
| PB14 | 35      | GPIO_OUT | 电机2 IN1       | 推挽输出，TB6612 IN1         |
| PB15 | 36      | GPIO_OUT | 电机2 IN2       | 推挽输出，TB6612 IN2         |
| PB6  | 85      | TIM4_CH1 | **舵机 PWM**    | 50Hz，1–2ms 脉宽（Servo 模块） |
| PE9  | 78      | TIM1_CH1 | 编码器 A（正交 CH1） | 接轮1 编码器 A 相             |
| PE11 | 80      | TIM1_CH2 | 编码器 A（正交 CH2） | 接轮1 编码器 B 相             |
| PA0  | 16      | TIM2_CH1 | 编码器 B（正交 CH1） | 接轮2 编码器 A 相             |
| PA1  | 17      | TIM2_CH2 | 编码器 B（正交 CH2） | 接轮2 编码器 B 相             |

**TB6612 接线补充**：

- 两路电机共用一片双路 TB6612（或两片单路）。PWM=PA6/PA7，方向=PB12–PB15。
- **STBY 脚在固件里没有分配** —— PCB 上建议直接拉到 3.3V（常使能）；若想软件控制待机，可改接一个空闲 GPIO（需改代码）。
- 编码器用正交 TI12 模式，A/B 两相分别接到对应 TIM 的 CH1/CH2，注意 A/B 别反（反了计数方向反，软件里可交换或取反）。

## 2. CAN 总线（底盘通信）

| 引脚  | LQFP100 | 功能      | 接什么                            |
| --- | ------- | ------- | ------------------------------ |
| PB9 | 88      | CAN1_TX | CAN 收发器 TXD（如 TJA1051/TJA1042） |
| PB8 | 87      | CAN1_RX | CAN 收发器 RXD                    |

- 500 kbps（`ros.ioc`：prescaler=7，BS1=8TQ，BS2=3TQ，SJW=1TQ）。
- **注意**：`Hardware/OLED.c` 里把 PB8/PB9 当软件 I2C 用了（见第 4 节），那是搬来的死代码，**板子上 PB8/PB9 只能给 CAN**，别接 OLED。

## 3. USB_OTG_FS（调试/通信，可选但已配）

| 引脚   | LQFP100 | 功能     | 接什么                           |
| ---- | ------- | ------ | ----------------------------- |
| PA11 | 44      | USB_DM | USB 座 D−                      |
| PA12 | 45      | USB_DP | USB 座 D+                      |
| PA10 | 43      | USB_ID | OTG ID（纯作 device 时接地或悬空由座子决定） |

- Device 模式：DP 需 **1.5kΩ 上拉到 3.3V**（部分座子/控制器内部已处理，确认后再加）。
- D+/D− 串 **22Ω** 阻尼电阻；走差分，等长、远离噪声。
- ⚠️ `Hardware/MyI2C.c` 把 PA12 当 I2C SCL 用，也是死代码，**PA12 只能给 USB**。

---

## 4. ⚠️ 冲突与缺口：软件 I2C（MPU6050 / OLED）

`Hardware/` 下的 `MyI2C.c`（MPU6050）、`OLED.c`（OLED）是从 **STM32F1 工程原样搬来的**，引脚宏没改，和本板实配**直接冲突**，且当前固件里 `MPU6050.c`/`OLED.c` 并**没有被调用**（`oled_app.c` 是 0 字节空文件）。

| 外设                | 代码里写的脚              | 实际已被占用为                  |
| ----------------- | ------------------- | ------------------------ |
| MPU6050 (MyI2C.c) | SCL=PA12 / SDA=PB13 | PA12=USB_DP，PB13=电机1 IN2 |
| OLED (OLED.c)     | SCL=PB8 / SDA=PB9   | PB8=CAN1_RX，PB9=CAN1_TX  |

**结论**：若板子要带 MPU6050 和 OLED，必须重新选脚并改代码；当前这俩外设处于"有库无连接"状态。

### 推荐重分配（软件 I2C，任意 GPIO 均可，建议开漏）

| 外设      | 新 SCL               | 新 SDA        | 改哪行代码               |
| ------- | ------------------- | ------------ | ------------------- |
| MPU6050 | PC0 (LQFP100 pin 8) | PC1 (pin 9)  | `MyI2C.c` 第 2–3 行   |
| OLED    | PB0 (pin 27)        | PB1 (pin 28) | `OLED.c` 第 99、116 行 |

要点：

- 这两组脚在 `gpio.c` 里**没有初始化**，需在 `MX_GPIO_Init()` 里补 GPIO 开漏输出 + 外部 4.7kΩ 上拉（I2C 总线必须上拉到 3.3V）。
- MPU6050 地址脚 AD0 接地（地址 0x68）/ 接 VCC（0x69）。
- 如果不带这俩外设，直接在 PCB 上省掉，不影响其它功能。

## 5. 急停输入（安全相关，重点核）

| 引脚  | LQFP100 | 功能             | 接什么  |
| --- | ------- | -------------- | ---- |
| PE1 | 70      | EXTI1，下降沿，内部上拉 | 急停按钮 |

- 固件逻辑（`physical_estop.c`）：**引脚读到低电平 = 急停触发**（`GPIO_PULLUP` 已开）。
- 接法：PE1 经内部上拉，常态为高（安全）；急停按钮把 PE1 拉到 GND → 低电平 → 触发。推荐用 **常开（NO）按钮接 PE1→GND**。
- ⚠️ 代码注释写的是"normally-closed/active-low"，与实际电平逻辑（低=触发、上拉）**不自洽**。打板前确认安全语义：若要走工业 NC（断线也报警）方案，需要外部上拉+常闭串联，并反过来改固件判据。当前固件按"低电平=触发"实现。

## 6. 调试 / 时钟 / 晶振

| 引脚   | LQFP100 | 功能                       |
| ---- | ------- | ------------------------ |
| PA13 | 46      | SWDIO（调试）                |
| PA14 | 48      | SWCLK（调试）                |
| PH0  | 5       | HSE 8MHz 输入（外部晶振）        |
| PH1  | 6       | HSE 8MHz 输出              |
| PC14 | 3       | LSE 32.768kHz 输入（RTC，可选） |
| PC15 | 4       | LSE 32.768kHz 输出（可选）     |

- HSE 用 8MHz 无源晶振 + 两端 22pF 到地，负载电容按晶振规格调。HSE 是系统时钟源（PLL→168MHz）。
- LSE 仅 RTC 用，不接也能跑；接了就按 32.768k 配负载电容。
- SWD 4 线（SWDIO/SWCLK/+3.3V/GND）引到排针，方便烧录调试。

## 7. 电源 / 复位 / 启动（特殊脚，缺一不可）

| 网络         | LQFP100 脚                      | 要求                                                 |
| ---------- | ------------------------------ | -------------------------------------------------- |
| VDD (3.3V) | 1, 20, 36(?), 50(?), 75, 100 等 | **每个 VDD 旁 100nF + 尽量 10µF**；具体脚号以 datasheet 引脚表为准 |
| VSS (GND)  | 与 VDD 配对的多个                    | 每个 VSS 就近打地过孔                                      |
| VDDA       | 15                             | 模拟 3.3V，**独立 LC/磁珠** 隔离数字电源，旁 100nF+1µF            |
| VSSA       | 12                             | 模拟地，单点接数字地                                         |
| VREF+      | 14                             | 接 VDDA（若不用 ADC 外部参考）                               |
| VREF−      | 13                             | 接 VSSA                                             |
| VCAP_1     | 47                             | **2.2µF 到 GND**（内核稳压，必接）                           |
| VCAP_2     | 98                             | **2.2µF 到 GND**（必接）                                |
| NRST       | 7                              | 10kΩ 上拉到 3.3V + 100nF 到 GND；可并一个复位按钮到地             |
| BOOT0      | 94                             | 10kΩ 下拉到 GND（从 Flash 启动）；想进 DFU 可加跳线到 3.3V         |
| VBAT       | 1                              | 接 3.3V 或纽扣电池（RTC 备份域供电）                            |

> VDD/VSS 具体脚号在不同封装脚位表里有明确列表，请逐对核对；**任何一对 VDD/VSS 漏接都会局部不工作**。

## 8. 未使用引脚建议

- 本设计只用了 F407 很小一部分 IO，剩余（PC0–PC15 多数、PDx、PE0/PE2–PE15 多数、PA2–PA5、PA8–PA9、PB0–PB5、PB7、PB10–PB11 等）均为空闲。
- 空闲脚在固件里作浮空输入即可；PCB 上可：
  - 留测试点 / 排针，方便以后扩展；
  - 或设为输出固定电平并贴 0Ω 到地（降低 EMI，非必须）。
- 扩展 MPU6050/OLED 已在上文占用 PC0/PC1/PB0/PB1，剩余仍很多。

## 9. 打板前必查清单

- [ ] PB8/PB9 只接 CAN 收发器，不接 OLED（删掉 OLED.c 里的 PB8/PB9 用法或重分配）
- [ ] PA12 只接 USB DP，不接 I2C SCL
- [ ] 决定 MPU6050 / OLED 是否上板；若上，按第 4 节改代码 + 补 GPIO 初始化 + 加 4.7k 上拉
- [ ] TB6612 STBY 处理（拉高常使能 / 接 GPIO）
- [ ] 急停安全语义确认（当前：PE1 低电平触发，建议 NO 按钮接 GND）
- [ ] VCAP_1/VCAP_2 各 2.2µF 到地
- [ ] 所有 VDD/VSS 成对去耦
- [ ] HSE 8MHz 晶振 + 负载电容；USB DP 1.5k 上拉
- [ ] SWD 4 针引出
- [ ] BOOT0 下拉（Flash 启动）
