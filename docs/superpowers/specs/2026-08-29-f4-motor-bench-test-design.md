# F4 电机台架驱动试验设计

## 目标

验证 STM32F4 到 TB6612FNG 的完整硬件链路确实能够驱动电机。该试验只验证开环 PWM 与方向输出，不验证 CAN、编码器或 PID。

## 硬件映射

- 1 号电机：`TIM3_CH1 / PA6` 输出 PWM，`PB12/PB13` 输出方向。
- 2 号电机：`TIM3_CH2 / PA7` 输出 PWM，`PB14/PB15` 输出方向。
- PWM 频率为 20 kHz，内部占空比使用 `0..1000`。
- TB6612 的 `STBY` 按现有硬件连接保持有效；不新增 MCU 控制线。

## 测试时序

启动后先完成 GPIO、TIM3 和电机驱动初始化，并确保两路处于 COAST。随后只执行一次：

1. 1 号电机正转，PWM 为 `200/1000`，持续 3 秒。
2. 关闭 1 号 PWM 并设置 COAST，等待 1 秒。
3. 2 号电机正转，PWM 为 `200/1000`，持续 3 秒。
4. 关闭 2 号 PWM 并设置 COAST，之后保持安全状态。

测试由 `MOTOR_BENCH_TEST` 编译开关控制，默认关闭。未开启时，程序继续进入现有 `Chassis_ControlInit()` 和主循环。

## 安全与验收

- 测试前车轮架空，电机电源限流；测试期间不连接负载或人为阻挡转轴。
- 验收条件：复位后能观察到 1 号电机先转、停止后 2 号电机再转；两段结束后两路均为 COAST。
- 固件测试完成后重新构建并烧录默认关闭 `MOTOR_BENCH_TEST` 的普通固件，恢复原控制入口。
