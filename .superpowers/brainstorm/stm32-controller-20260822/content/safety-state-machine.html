任意状态可进入

ESTOP · 0x0001

入口：PE1 低电平，或任一合法格式命令帧带 estop bit。立即 PWM=0，再令两路 IN1=IN2=1 短刹；清 PI；故障锁存。

退出：PE1 连续释放 50 ms、CAN estop 清零，并收到新的全零 STOP 双帧组 + reset_fault_request。只回到 STOPPED，不直接进 ACTIVE。

设备故障

FAULT

入口：编码器、驱动、看门狗复位或未知设备故障。电机 COAST，舵机保持安全标定目标或禁用。

退出：仅当物理原因消失且该 fault 的协议策略允许清除；全零 STOP + reset 请求后回 STOPPED。不可软件清除的故障需人工检修/重新标定。

状态不等于 fault code：非锁存协议错误可上报 fault 而保持 STOPPED/SAFE_STOP；状态机负责“能不能输出”，fault code 负责“为什么不能输出”。同一时刻按严重度只发布一个主 fault，同时内部保留诊断位。
